# GitHub Profile Card

Веб-приложение, в которое вводишь GitHub-юзернеймы и получаешь карточки с информацией о пользователях: аватар, имя, био, статистика, последние репозитории и топ языков. Можно сравнивать двух пользователей бок о бок. Утилита для быстрого просмотра GitHub-профилей.

## Стек

- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства (CSS-переменные), Grid, Flexbox, анимации, адаптивная вёрстка
- **JavaScript (ES6+)** — async/await, Fetch API, работа с DOM, localStorage
- **GitHub REST API v3** — публичное API (с опциональной авторизацией через токен)

Без фреймворков и библиотек: чистый ванильный стек.

## Что работает

- **Сравнение двух пользователей** — чекбокс «Сравнить» открывает второе поле ввода, результаты отображаются бок о бок в двух колонках
- **Поиск пользователя** — ввод юзернейма + кнопка «Найти» или Enter
- **Карточка профиля** — аватар, имя, био, количество репозиториев, подписчиков и подписок
- **Последние 5 репозиториев** — с названием, описанием, языком, звёздами и форками
- **Сортировка репозиториев** — по обновлению, по звёздам, по дате создания
- **Топ языков** — подсчёт и визуализация языков программирования с цветными барами
- **Тёмная и светлая темы** — переключатель с сохранением выбора в localStorage
- **Случайный пользователь** — кнопка 🎲 выбирает случайного известного разработчика
- **Недавние поиски** — последние 5 юзернеймов сохраняются в localStorage, доступны по клику
- **Обработка ошибок** — понятное сообщение при 404 (пользователь не найден) и других ошибках
- **Индикатор загрузки** — спиннер с текстом «Загружаю...» во время запроса
- **GitHub токен** — опциональная авторизация увеличивает лимит запросов с 60 до 5000/час
- **Адаптивная вёрстка** — один пользователь занимает всю ширину, два — делят экран поровну

## Что не доделано

- Пагинация для репозиториев — при большом количестве репозиториев API возвращает только первые 100
- GitHub API без авторизации имеет лимит 60 запросов в час — при активном использовании можно упереться в лимит

## Что я узнал во время работы

- **Работа с GitHub REST API** — научилась делать запросы к публичным эндпоинтам `/users/USERNAME` и `/users/USERNAME/repos`, обрабатывать ответы и ошибки (особенно 404).
- **CSS-переменные для тем** — освоила технику переключения между тёмной и светлой темой через `data-theme` атрибут на `<html>` и набор CSS-переменных (`:root` и `[data-theme="light"]`). Тема сохраняется в `localStorage`.
- **Асинхронные запросы** — закрепила работу с `async/await` и `fetch`, обработку ошибок через `try/catch`, параллельные запросы к разным эндпоинтам API.
- **localStorage для UI-состояния** — сохраняла не только тему, но и историю поисков, что дало удобный UX без бэкенда.
- **Dark/Light Academia дизайн** — переработала визуальный стиль в эстетике старых университетов: тёплые коричневые тона, шрифты Georgia, золотые акценты, декоративные элементы (✦), эффект сепии на аватарах.
- **CSS Grid для сравнения** — научилась переключать `grid-template-columns` между `1fr` (один пользователь) и `1fr 1fr` (режим сравнения) через динамический класс `.compare-mode`.
- **Выравнивание карточек** — решила проблему разной высоты карточек при сравнении через `align-items: stretch`, `height: 100%` на колонках и `line-clamp` для обрезки длинного текста.
